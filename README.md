### EN
# Ranteen

**Ranteen** is a modern web application that solves the problem of the lack of effective feedback in school canteens. The application allows students to rate and comment on meals, and provides the administration with valuable data to optimize the menu, reduce food waste and better plan.

## 🚀 Key Features

- **User Management:** Two types of accounts: **Student** (login via Google SSO) and **Administrator** (login/password) with a verification system for new accounts and division into roles.
- **Menu Management:** Administrators can create, edit and plan daily menus, adding descriptions, photos and categories of dishes (e.g. soup, main course, vegetarian).
- **Rating and Comment System:** Students can rate dishes on a scale of 1-5 stars and add text comments. Ratings are associated with a specific day of serving the dish.
- **Content Moderation:** Automatic profanity filtering and a comment moderation panel available to administrators.

- **Statistics and Reports:** Generate reports on dish popularity, trend analysis, and the ability to export data to CSV/Excel for administration.

## 🛠️ Architecture and Technology Stack

- **Frontend:** Built in **React.js** with **React Router** for navigation.

- **Backend:** Based on **Node.js** with the **Express.js** framework, providing a REST API.

- **Database:** Non-relational **MongoDB** database with the **Mongoose** library as ORM.



### PL
# Ranteen

**Ranteen** to nowoczesna aplikacja webowa, która rozwiązuje problem braku efektywnego feedbacku w szkolnych stołówkach. Aplikacja pozwala uczniom oceniać i komentować posiłki, a administracji dostarcza cennych danych do optymalizacji menu, redukcji marnowania żywności i lepszego planowania.

## 🚀 Kluczowe Funkcjonalności

-   **Zarządzanie Użytkownikami:** Dwa typy kont: **Uczeń** (logowanie przez Google SSO) i **Administrator** (login/hasło) z systemem weryfikacji nowych kont i podziałem na role.
-   **Zarządzanie Menu:** Administratorzy mogą tworzyć, edytować i planować dzienne menu, dodając opisy, zdjęcia i kategorie dań (np. zupa, danie główne, wege).
-   **System Ocen i Komentarzy:** Uczniowie mogą oceniać dania w skali 1-5 gwiazdek i dodawać komentarze tekstowe. Oceny są powiązane z konkretnym dniem serwowania potrawy.
-   **Moderacja Treści:** Automatyczne filtrowanie wulgaryzmów oraz panel moderacji komentarzy dostępny dla administratorów.
-   **Statystyki i Raporty:** Generowanie raportów popularności dań, analiza trendów i możliwość eksportu danych do formatu CSV/Excel dla administracji.
